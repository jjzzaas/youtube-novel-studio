# Protagonist voice reference

Place the user's own clean voice sample here as `reference.wav` when available.

Recommended source:
- 1–3 minutes of natural Korean speech
- quiet room, no music/TV/reverb
- normal speaking voice rather than exaggerated acting
- one speaker only

The production pipeline must fall back to the configured preset voice when the reference file is absent. The reference is intended only for the user's own voice or a voice supplied with explicit permission.
